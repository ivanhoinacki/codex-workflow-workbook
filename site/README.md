# Codex Workflow Workbook Site

Interactive workbook built with Vite and React.

## Commands

```bash
source ~/.nvm/nvm.sh
nvm use
npm install
npm run dev
npm run build
```

The Vite base path is configured for GitHub Pages:

```text
/codex-workflow-workbook/
```

The app loads Markdown from `../docs/` and stores progress in `localStorage`.
